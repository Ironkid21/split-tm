# Split TM

Offline desktop app to filter, split and export TMX files and ZIP packages of TMX (TMX, Excel, CSV, Markdown). Windows and macOS.

- **Users:** install, double-click, drop in `.tmx` / `.zip` files, pick Brand/Approval/Project/dates, choose a format, Process. Results are in `Documents/Split TM/TMX Output/<date>/<run id>/`; the history is in one `Processing_Log.xlsx` in the app-data folder.
- **Developers:** see [DEVELOPER.md](DEVELOPER.md). Quick start: `npm ci && npm run dev`, then `npm run verify`.
- **Release / packaging / upgrades:** see [PACKAGING.md](PACKAGING.md).
